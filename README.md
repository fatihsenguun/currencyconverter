# 🪙 Currency Converter

A simple and responsive **React** application that converts between different currencies using real-time exchange rates fetched from the **FreeCurrencyAPI**.

---

## 🚀 Features
- 🔄 Real-time exchange rate fetching via API
- ⚙️ Built with **React**, **Axios**, and **Bootstrap**
- 🎨 Simple and responsive user interface

---

## 🧠 Tech Stack
- **React.js** – Frontend framework  
- **Axios** – For API requests  
- **Bootstrap** – For layout and styling  
- **FreeCurrencyAPI** – Live exchange rates
